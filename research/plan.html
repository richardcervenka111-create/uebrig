  • uebrig.ch → GitHub Pages (repozitár uebrig): 4 záznamy A na IP GitHub Pages + CNAME www; v Cloudflare najprv DNS only (sivý oblak), aby GitHub vydal certifikát; potom sa v GitHube zapne „Enforce HTTPS“. Súbor CNAME v repozitári sa pridá až po nastavení DNS – inak by github.io adresa presmerovala na doménu, ktorá ešte nefunguje. Workflow už CNAME kopíruje, keď existuje.
  • kit.uebrig.ch → Bärn Kit (repozitár -brig): CNAME záznam na richardcervenka111-create.github.io, rovnaký postup. Bärn Kit je informačná appka zadarmo pre všetkých, súčasť projektu übrig – reklamný panel v hube vedie na übrig.
  • uebrig.de → 301 na uebrig.ch cez Cloudflare Redirect Rule (Free, bez servera).
  • Supabase Custom SMTP = Hostpoint: odosielateľ hallo@uebrig.ch, server a port podľa stránky „E-mail client settings“ v Control Paneli (spravidla asmtp.mail.hostpoint.ch, 465 SSL). Heslo zadáva Richard v Supabase Dashboard sám.
